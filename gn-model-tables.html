The chain

rate
rate_E(j) = LM_g0,t [+ trend_g0 x j if selected] + beta_g0(min(j,5)) x post + gamma_g0(min(j,5)) x (q - 0.5) + C_g0(a + j) - C_g0(a) + delta_j (pitchers on the per-IP bases); beta, gamma continuous in j between integer lags with beta(0) = 1, gamma(0) = 0
delta
delta_j = sum over target groups g1 of w_j(g1) x [(LM_g1,t - LM_g0,t) + delta'(g0 -> g1)], with delta'(g0 -> g0) = 0 and w_j(g1) the IP-weighted state mix (transition probabilities at lag j times each state's design-year mean IP, normalised). The league gap uses the flat (anchor-season) level, like LM itself.
skill
skill_j = max(0, rate_E(j)) x PT_full (PT_full = G_full(role) x iota); the per-game / per-start / per-appearance bases use G_full(role) x rate
role
role_j = 70 x sum_s w_j(s) x m_s(i), w_j(s) = P_j(s | s_t0, tercile) Gbar_s / sum_s' P_j(s') Gbar_s' (the appearance-weighted mix, resolution 2, SPEC 3.8 erratum; SP state 0; RP all-in bases: none)
U
U_j = 1.5 x logistic(eta_U); UG_j likewise; hk = (U x skill + UG x role) / (skill + role) for RP anchors, U otherwise
expected
tj = tjp x hk x f' (sc and fielding outside this fit; f' is the injury module's line)
SIGMA
display: SIGMA_j = running minimum of 1 / (1 + exp(-eta_SIGMA(j))) for j <= 8, extended by the last one-step conditional; A_j = U_j / SIGMA_j
S_prime
S' = min(1, S / SIGMA_pre(j_ret)), SIGMA_pre at the pre-episode covariates (SPEC 7.2). A rule, not a fit; the SIGMA coefficients it reads are frozen here.
q

The fit rule (declared_conventions.F3)
Anchors with a row at t, 2002 <= t <= 2011, lags 1-5, t+j <= 2012; survivors only (a row of the kind at t+j with units > 0); weight = units at t+j. Target = the league-relative rate at t+j against the target row's own group. Regressors: beta_j x post, gamma_j x (q - 0.5) for j = 1..5 (flat beyond 5); C(a+j) - C(a); pitchers on the per-IP bases add delta' x 1[target row group != anchor group]. C lives on single ages over the contiguous run of target ages with >= 30 pairs around the anchor age (26 hitters, 27 pitchers, where C = 0), with linear continuation at the end slopes beyond it. Penalty lambda x sum of squared second differences, lambda = c x W / n_ages with W the total weight, c on {1e-2, 1e-1, 1, 10, 1e2, 1e3, 1e4}, chosen by LOSO over target seasons on the full design fit and held fixed inside the CV folds.
